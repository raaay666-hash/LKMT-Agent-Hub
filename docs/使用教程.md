# LKMT Agent Hub 使用教程

LKMT Agent Hub 是 Windows 本机的工作区检查和智能体任务记录工具。当前版本为 **0.1.0-alpha**。你可以登记自己的项目、查看 Git 信息、记录任务进度和检查点，并检查本机恢复状态。

## 一、安装与启动

1. 运行 `LKMT Agent Hub_0.1.0-alpha_x64-setup.exe`，按提示安装。Windows 11 通常已带 WebView2；如提示缺少，请从微软官方渠道安装 Microsoft Edge WebView2 Runtime。
2. 从开始菜单打开 **LKMT Agent Hub**。程序使用中文界面。
3. 演示数据可能显示为 `DEMO - Task A`，它是测试记录，不代表真实项目任务。

安装包尚未签名，Windows 可能显示发布者未知。使用已有程序或官方发布来源前，请自行核对发布来源。安装和卸载功能没有在干净电脑上验证。

## 二、添加并检查项目

1. 点击左侧 **工作区**，输入项目根目录的完整路径，例如 `D:\GameDev\OurGame`，点击 **添加工作区**。
2. 点击左侧列表里的路径，查看 Git 是否可用、当前分支、HEAD、修改文件、差异统计和最近提交。
3. 展开 **AGENTS.md**、**已有 agent-handoff 任务** 和 **已有 agent-handoff 锁**，阅读项目规则与报告状态。项目不是 Git 仓库或文件夹离线时会显示错误，不会自动删除或修改文件。
4. **移除登记**仅从本应用的列表移除路径，不删除项目文件。已创建的任务记录不会随之删除。

## 三、创建任务和检查点

1. 打开 **任务**，选择已登记的 Git 工作区，填写任务名称、智能体身份（例如 `codex` 或 `dsh`）和目标，点击 **创建任务**。
2. 选中任务，在右侧填写已完成、剩余工作、下一步和注意事项；清单每行一项。
3. 点击 **创建检查点**。程序自动记录当前分支、HEAD、Git 状态、差异统计和修改文件指纹；Agent 填写的内容是报告，并非自动核实。
4. 如需继续工作，点击 **恢复任务**。任务的本机锁会被登记；结束当前 Agent 的工作可点击 **发起交接**，释放本机锁并将状态设为等待中。确认剩余工作为空且工作区与检查点一致后，可点击 **完成任务**。

## 四、中断与恢复

1. 打开 **总览**或选择任务，若显示 **需要恢复**，点击 **检查当前工作区**，展开比较结果，查看当前 Git 差异、修改文件、检查点和锁。
2. 仔细检查实际文件和 `AGENTS.md`，不要只相信检查点。若分支或 HEAD 与检查点不一致，程序显示冲突并阻止恢复；需要先在项目外分析和解决历史差异。
3. 若本机锁已过期，确认前一个 Agent 确实停止后，填写新 Agent 身份、勾选人工检查确认，再点击 **接管过期锁**。锁过期本身不证明 Agent 已停止。
4. 检查未记录的改动，填写恢复说明并创建恢复检查点，再点击 **恢复任务**。若项目存在原有 `.agent-state/locks/*.lock`，本应用会保守阻止恢复或接管，需按该项目的 agent-handoff 规则处理。

## 五、如何理解状态

- **已核实**：程序读到的 Git、文件或本机登记信息。
- **报告**：Agent 或用户填写的任务信息，需要到真实代码和 Git 中核对。
- **推断**：程序将当前工作区与检查点比较得出的结果，不等于确认 Agent 已中断。

审计记录在 **历史记录**中。数据位于 `%APPDATA%\org.lkmt.agenthub\hub.sqlite3`；请勿将该数据库提交到 Git，里面可能包含本机路径、任务说明等信息。

## 六、当前限制

锁和任务记录仅保存在本机，不具备跨电脑互斥。现有 agent-handoff 任务和锁只读展示，不能在 Hub 内直接完成原协议的 checkpoint/resume。GitHub 同步、NAS、远程在线状态及自动判断中断均尚未实现。工作区的 Git 暂存区存在少量未单独指纹化的变化情形，恢复前仍需人工检查。程序不会自动读取 AI 的私人聊天或内部思考。

## 七、从源码运行

安装 Node.js、Rust、Microsoft C++ Build Tools 和 WebView2 后，在项目目录运行：

```powershell
npm install
npm run tauri dev
```

运行测试：`cargo test --manifest-path src-tauri/Cargo.toml`；构建安装包：`npm run tauri build`。更多已验证范围见 `docs/VALIDATION.md`。
